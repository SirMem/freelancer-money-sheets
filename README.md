## Market class (ratings gate)

Before cutting price or stacking SKUs: classify buyer search terms as Paid / Free / Empty by Gumroad page-1 **ratings** (not competitor counts). See [MARKET-CLASS.md](MARKET-CLASS.md). 2026-10-28 snapshot: Invoice/Expense/Client stay paid as **Trackers**; Aging stays free (dead `aging receivables` room).

## Pain-split (situation gate)

SKU tiers split by **buyer situation / precondition**, not a price ladder. Same-job SKUs at $5–6 cannibalize. See [PAIN-SPLIT.md](PAIN-SPLIT.md). 2026-10-28: Invoice = late pay/AR · Expense = tax/Schedule C · Client = pipeline not money · Bundle = already decided all three. Each free money sample feeds exactly one paid SKU; ADHD/RE stay free-only.


## Owned list (nurture gate)

Free-download count is vanity. Segment by which free SKU they took; each segment maps to **at most one** paid CTA (Aging → Invoice; Expense → Expense; Client → Client). ADHD/RE free stay soft-only (no cross-ICP money-tracker pitch). See [OWNED-LIST.md](OWNED-LIST.md). Paste-ready sequences live under sidehustle `owned-list-nurture-v1/SEQUENCES.md` (not auto-sent).

## Payout email lock (send gate)

Until Gumroad ≥$100 **net after fees** and a completed payout, platform Emails/Workflows/Broadcasts cannot send. Free SKUs still capture addresses; writing a Workflow is **not** nurture. Pre-unlock = CSV export + offboard 3-touch (sidehustle `payout-email-lock-v1/`). See [PAYOUT-EMAIL-LOCK.md](PAYOUT-EMAIL-LOCK.md).


## Warm-first sale (Discover gate)

Discover / cold in-platform traffic stays at **zero** until a paid product has ≥1 counted successful sale (then ratings help). Bootstrap with off-platform warm asks — do not wait on listing SEO or free downloads. See [WARM-FIRST.md](WARM-FIRST.md). Practice scripts: sidehustle `warm-first-sale-v1/`.
**Warm sequencing:** first DM/community help = no link; round 2 only after real AR reply. See [WARM-SEQUENCING.md](WARM-SEQUENCING.md). Scripts: sidehustle `warm-seq-no-link-v1/`.
**Owner favor:** agent cannot mint first-sale warm — clear B with one chat reply A/B ([CHAT-REPLY-FORMAT.md](CHAT-REPLY-FORMAT.md)); WeChat paste + PNG ([ONE-TAP-POST.md](ONE-TAP-POST.md), `assets/wechat-friday-chase-share.png`). **Lowest activation (GATE-IN-CHANNEL + REPLY-BIND):** [chat-inline-clear.md](chat-inline-clear.md) in the open chat — one paste ↔ bound reply; do not require opening HTML first; do not present A∥C as equal ([GATE-IN-CHANNEL.md](GATE-IN-CHANNEL.md) · [REPLY-BIND.md](REPLY-BIND.md) · [CLEAR-COST.md](CLEAR-COST.md) · [scorecard](reply-bind-scorecard.html)). Gates: [OWNER-FAVOR-GATE.md](OWNER-FAVOR-GATE.md) + [ACTIVITY-BIAS-LOCK.md](ACTIVITY-BIAS-LOCK.md) + [ACTIVITY-BIAS-48H.md](ACTIVITY-BIAS-48H.md) ([scorecard](activity-bias-scorecard.html)).
**Audience rent:** after (or alongside) owner favor, cheapest *scale* distribution is commission partners with `/a/` links — not more awesome PRs. Empty join page = fancy 404; progress = personalized recruit with **USECASE-OPEN** (scene before rate) + **TEST-NOT-DEAL** (7-day paste-test close, not join). See [AUDIENCE-RENT-GATE.md](AUDIENCE-RENT-GATE.md) + [AUDIENCE-RENT-PARTNER-KIT.md](AUDIENCE-RENT-PARTNER-KIT.md) + [AUDIENCE-RENT-RECRUIT.md](AUDIENCE-RENT-RECRUIT.md) + [AUDIENCE-RENT-HOOK.md](AUDIENCE-RENT-HOOK.md) + [AUDIENCE-RENT-TEST.md](AUDIENCE-RENT-TEST.md) + [partner.html](https://sirmem.github.io/freelancer-money-sheets/partner.html) + [usecase scorecard](https://sirmem.github.io/freelancer-money-sheets/usecase-open-scorecard.html) + [test scorecard](https://sirmem.github.io/freelancer-money-sheets/test-not-deal-scorecard.html).
