学生/新人接私活：客户晚付钱，本周先催谁？

披露：本页教一套免费的「本周先催谁」小仪式；可选付费 tracker 仅作「样本不够再用」。示例金额与客户名为虚构 EXAMPLE，非法律/税务/催收建议。作者侧有免费 Aging 样本与付费表（Gumroad Jennifer Keith / keithjenn）。

先回答一个问题

接私活、做兼职、帮人做设计/剪辑/代写/小程序时，客户晚付钱很常见。你真正缺的通常不是「更狠的话术」，而是：本周先催谁？

微信聊天、备忘录、截图散落一地时，容易一直追刚交的大单，却漏掉拖了两个月的小单。

四档账龄：Current / 1–30 / 31–60 / 60+

把每笔未收款放进四档之一：

档位含义本周倾向
Current尚未到期（或今天到期）先看着，别催
1–30 天刚逾期金额或关系重要再礼貌提醒
31–60 天卡住了升级语气/换渠道；确认对方收到账单
60+ 天危险区通常先催（除非你已打算放弃）

免费中文样本用 EXAMPLE 行展示公式（人民币 ¥）；你把自己的客户名和金额换进去即可。

15 分钟仪式

  1. 打开账龄表，填上「截至今天」的日期。
  2. 确认每笔未收都在四档之一（Current / 1–30 / 31–60 / 60+）。
  3. 按逾期天数排序（不要按金额）。金额大但刚逾期的，会盖住拖了很久的小单。
  4. 只挑 top3。写到便签或日历。
  5. 今天下午就催这三笔。停。别先重建整本账。

常见坑：开五个聊天窗口「看看谁还没付」，却没有一张统一的逾期视图。
