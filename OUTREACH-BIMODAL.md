# OUTREACH-BIMODAL · 名单质量二分（NEW core · 非 *-GATE）

**One-liner（CN）：** 冷触达回复率是二分的，不是连续刻度——≤50 条手筛名单常见 14–58% 回复且能出首单；≥300 条刮号名单常见 ~1% 回复且首单≈0；变量是名单与你对对方已知事实，不是文案量。

**English short:** Cold-outreach reply rates are **bimodal, not continuous**. Hand-qualified lists ≤50 often return **14–58%** replies and ≥1 paying customer; scraped lists ≥300 often return **~1–1.6%** replies and ≈0 first sales. The variable is **list quality + known facts about the recipient**, not copy volume.
