How to write a real estate listing description with ChatGPT prompts

If you are a solo or small-team residential agent, you already have the facts — beds, baths, sqft, price, HOA. What stalls the listing is turning those facts into MLS-safe copy before the photos go live. A prompt pack fixes that in one sitting: pick a public copy framework, fill brackets with your numbers, paste into ChatGPT (or any chat model), then edit before you publish.

This page is the complete method. At the end you can open a free pack of 16 prompts with EXAMPLE outputs against a clearly marked fake property listed at $1,185,000. Not a CRM. Not fair-housing legal advice.

The 4-step method (complete)

  1. Pick one framework for the job. Full MLS body → AIDA. Soften a buyer objection → PAS. Specs that feel flat → feature → benefit. Open-house window → time-bound urgency only (real date/time).
  2. Fill every [BRACKET] with verified listing facts: address, beds/baths/sqft/year, price, 2–3 standout features, neighborhood note, CTA. Do not invent amenities, views, or school ratings.
  3. Paste into ChatGPT (Claude / Gemini / your brokerage-approved model also fine). Ask for one draft, not five rewrites in the same shot.
  4. Edit before MLS / social publish. Check fair-housing language, brokerage rules, and every number against the sheet. The model drafts; you own the final copy.

EXAMPLE prompt snippet #1 — MLS body (AIDA)

Shortened from free pack prompt #1. Replace brackets with your facts.

You are a residential listing copywriter. Write an MLS-style property description using AIDA (Attention → Interest → Desire → Action).

Facts:
- Address: [ADDRESS]
- Beds/Baths/Sqft/Year: [BEDS] / [BATHS] / [SQFT] / [YEAR]
- Price: [PRICE]
- Standout features: [FEATURE1], [FEATURE2], [FEATURE3]
- Neighborhood note: [NEIGHBORHOOD]
- Call to action: invite a private tour / open house on [DATE]

Rules: 180–240 words. No invented amenities. No income or investment promises. Neutral fair-housing language. End with a clear next step.

EXAMPLE output (fake property — do not copy these facts onto a real MLS sheet):

EXAMPLE PROPERTY · 1847 Maple Grove Lane, Riverside Oaks, CA 90210 · 4 bed / 3 bath · 2,280 sqft · built 2012 · $1,185,000 · pool · quiet cul-de-sac · HOA $95/mo

Step onto Maple Grove and the cul-de-sac hush hits first — then the turquoise pool flashing behind glass. This 4-bed, 3-bath, 2,280 sqft home (built 2012) keeps everyday life easy… Listed at $1,185,000 with a modest $95/mo HOA. Tour privately or join the open house Saturday 1–3.

EXAMPLE prompt snippet #2 — feature → benefit

Turn each feature into one benefit-led bullet (feature → so you can…). Keep each under 22 words. No invented features.

Features: [LIST FEATURES ONE PER LINE]
Audience: [BUYER TYPE, e.g. growing family / WFH couple]

EXAMPLE lines from the fake Maple Grove listing:

  • Cul-de-sac lot → so weekend bikes stay off through-traffic.
  • 2,280 sqft open plan → so cooking, homework, and guests share one sightline.
  • Pool + covered patio → so summer hangs don’t need a reservation.
